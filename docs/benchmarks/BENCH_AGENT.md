# BENCH_AGENT.md — end-to-end / agent-facing results

> Generated by `bench/synth-agent.mjs`. Section 1 is a deterministic retrieval proxy for every language; section 2 is the per-task token footprint; section 3 is the LLM agent-trace on a small subset (heavy — "not run" elsewhere). Archetypes: **kw**=keyword/symbol lookup, **nl**=behavioural natural language, **xc**=cross-cutting.

## 1. Per-archetype retrieval proxy (strict rank-1 / s@5)

Default path (L1) and the best-available embedding/rerank config, per language. "Task success" proxy = the right symbol is in top-5 (s@5); the harder bar (rank-1) = it is #1. **Each archetype cell is `r1% / s@5% (n)`** — `n` is the per-language query count for that archetype. These are **small sets (n=2–14)**; nl/xc (behavioural) n is typically 2–4, so a single query moves rank-1 by 25–50 points. Read them as directional; the symbolic (kw) channel has the larger n.

> Archetypes here are `kind`-based (kw/nl/xc), which differs slightly from the `difficulty:"semantic"` subset used for the `sem` columns in BENCH_SUMMARY/LANGUAGES. **Structural gaps (which languages lack call-graph / type_refs) are the canonical, invocation-verified table in BENCH_LANGUAGES.md — not re-derived here.**
