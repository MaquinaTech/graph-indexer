# BENCH_LANGUAGES.md — per-language configuration matrix

> Generated by `bench/synth.mjs` from `bench/results/*.json`. Every cell is an extracted number from a **cold, isolated** build (`rm -rf .graph-indexer` before each), scored by `test/evaluate.mjs` with strict symbol-level ground truth. No ranking code was tuned. "not run" = a configuration that could not run, with the reason.

**Configurations.** **L1** = lexical + stemming (shipped default) · **E0** = in-process all-MiniLM-L6-v2 (current default embedder) · **E1** = in-process jina-embeddings-v2-base-code · **O0** = Ollama nomic-embed-text · **O2** = Ollama qwen3-embedding:4b · **R0** = O2 + LLM rerank (qwen2.5-coder:7b) · **R1** = O2 + LLM enrichment (qwen2.5-coder:1.5b) · **R2** = O2 + enrichment + rerank (full stack). (L0 = lexical-without-stemming is *not separately measurable* — stemming is not runtime-togglable; L1 is the shipped lexical floor. O1 = qwen3-embedding:0.6b is **not run — model not pulled**.)

Strict metrics are primary. `s@5`=strict success@5, `r1`=strict rank-1 accuracy, `MRR`=strict MRR, `sem`=behavioural/semantic-query subset (`difficulty:"semantic"`), `held`=held-out validation split (never used to tune), `file-only`=loose-hit-but-not-strict inflation. **Per-language `sem` query counts (`n`) are small (n=2–7); a single query moves `sem r1` by 14–50 points — read those columns as directional, with the `sem n` printed under each language.**
